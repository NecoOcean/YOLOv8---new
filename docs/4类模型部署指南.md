## 3. 切换到4类模型

### 方法一：使用命令行脚本
```bash
python scripts/switch_config.py 4
```

### 方法二：在代码中切换
```python

# 切换到4类模式
settings.set_mode('cls4')

# 获取当前配置
config = settings.get_current_config()
```

如果UI支持，点击菜单中的"4类配置"选项即可切换。

## 4. 推理使用方法

### 单张图片检测
```python
import sys
sys.path.insert(0, 'd:/Data/code/YOLOv8 - new')

from src.config import settings
from src.core.detection_service import DetectionService

# 确保使用4类配置
settings.set_mode('cls4')

# 初始化检测服务
detector = DetectionService()

# 检测图片
result = detector.detect('path/to/your/image.jpg')

# 获取检测结果
print(f"检测到 {result.count} 个目标")
for i, (cls_id, conf) in enumerate(zip(result.classes, result.confidences)):
    config = settings.get_current_config()
    ch_name = config['CH_names'][cls_id]
    guide = config['classification_guide'][cls_id]
    print(f"  {i+1}. {ch_name} (置信度: {conf*100:.2f}%) - {guide['tip']}")

# 保存带标注的图片
import cv2
plotted_image = result.get_plotted_image()
cv2.imwrite('output/detected_result.jpg', plotted_image)
```

### 批量图片检测
```python
from pathlib import Path
import cv2

# 获取目录中所有图片
image_dir = Path('path/to/images')
image_files = list(image_dir.glob('*.jpg')) + list(image_dir.glob('*.png'))

# 批量检测
for img_path in image_files:
    result = detector.detect(str(img_path))
    if result.has_detections:
        print(f"{img_path.name}: 检测到 {result.count} 个目标")
        # 保存结果
        plotted = result.get_plotted_image()
        cv2.imwrite(f'output/{img_path.stem}_detected.jpg', plotted)
```

### 视频检测
```python
import cv2

# 打开视频文件
cap = cv2.VideoCapture('path/to/video.mp4')

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break
    
    # 检测当前帧
    result = detector.detect(frame)
    plotted_frame = result.get_plotted_image()
    
    # 显示结果
    cv2.imshow('Detection', plotted_frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

### 摄像头实时检测
```python
import cv2

# 打开摄像头
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    result = detector.detect(frame)
    plotted_frame = result.get_plotted_image()
    
    # 显示分类指导
    guides = result.get_classification_guide()
    for guide in guides:
        print(f"{guide['name']}: {guide['tip']}")
    
    cv2.imshow('Live Detection', plotted_frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

## 常见问题

### Q1: 模型加载失败
确保 `best_4cls.pt` 文件存在于 `data/models/trained/` 目录下。

### Q2: 类别显示错误
运行 `python scripts/switch_config.py 4` 切换到4类配置。

### Q3: UI无法切换配置
检查 `UIProgram/UiMain.py` 是否包含 `actionConfig4` 菜单项。
