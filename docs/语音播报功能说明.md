# 语音播报功能说明

## 功能概述

系统现已支持语音播报功能！当检测到垃圾时，会自动语音提示应该投入哪个垃圾桶。

## 主要特性

### 1. 智能播报
- **自动识别垃圾类别**：根据检测结果自动判断垃圾分类
- **精准语音提示**：明确指示投入对应颜色的垃圾桶
  - 🟢 绿色厨余垃圾桶
  - 🔵 蓝色可回收物垃圾桶
  - 🔴 红色有害垃圾桶
  - ⚫ 灰色其他垃圾桶

### 2. 防频繁播报
- **智能间隔控制**：默认3秒内不重复播报相同类别
- **视频模式优化**：摄像头/视频播放时自动控制播报频率
- **避免信息过载**：只在检测结果变化时播报

### 3. 灵活控制
- **一键开关**：界面上提供"🔊 启用语音播报"复选框
- **实时切换**：可随时启用或禁用语音播报
- **状态提示**：状态栏显示语音播报当前状态

## 使用方法

### 安装依赖

首先需要安装语音播报库：

```bash
pip install pyttsx3
```

或者重新安装所有依赖：

```bash
pip install -r requirements.txt
```

### 启用/禁用语音播报

在主界面的"操作控制"区域，找到"🔊 启用语音播报"复选框：
- ✅ 勾选：启用语音播报
- ⬜ 取消勾选：禁用语音播报

### 使用场景

#### 1. 图片检测
打开图片后，系统会自动语音播报检测到的垃圾类别。

**示例播报内容：**
- 单个类别：`"检测到厨余垃圾，请投入绿色厨余垃圾桶"`
- 多个类别：`"检测到多种垃圾。检测到可回收物，请投入蓝色可回收物垃圾桶；检测到其他垃圾，请投入灰色其他垃圾桶"`

#### 2. 视频/摄像头检测
在视频播放或摄像头实时检测时：
- 自动检测每一帧
- 当检测结果变化时进行播报
- 智能控制播报频率，避免过于频繁

#### 3. 文件夹批量检测
切换图片时会自动重置播报缓存，确保每张图片都能得到正确的语音提示。

## 技术实现

### 核心组件

**VoiceService 类** (`src/core/voice_service.py`)
- 基于 `pyttsx3` 跨平台语音引擎
- 线程安全的播报机制
- 智能缓存控制

### 播报逻辑

```python
# 播报流程
检测到垃圾 → 获取分类信息 → 判断是否需要播报 → 生成播报文本 → 语音播报
```

### 防频繁机制

1. **时间间隔控制**：3秒内不重复播报
2. **类别缓存**：记录上次播报的类别，相同则跳过
3. **自动重置**：切换图片/停止视频时重置缓存

## 配置选项

可以通过修改代码调整语音参数：

```python
# 在 app.py 的 _init_components 方法后添加
self.voice_service.set_rate(150)  # 语速：100-200
self.voice_service.set_volume(0.9)  # 音量：0.0-1.0
self.voice_service.set_announcement_interval(3.0)  # 播报间隔（秒）
```

## 故障排除

### Windows 系统

如果遇到语音引擎初始化失败：

```bash
# 安装 pywin32（Windows 平台）
pip install pywin32
```

### Linux 系统

需要安装 espeak：

```bash
# Ubuntu/Debian
sudo apt-get install espeak

# Fedora/CentOS
sudo yum install espeak
```

### macOS 系统

macOS 自带语音引擎，无需额外配置。

### 常见问题

**Q: 语音播报没有声音？**
- 检查系统音量是否打开
- 确认复选框是否勾选
- 查看终端是否有错误提示

**Q: 播报太频繁或不够频繁？**
- 可以调整 `announcement_interval` 参数
- 默认为3秒，可根据需要修改

**Q: 播报语速太快或太慢？**
- 调用 `set_rate()` 方法修改语速
- 推荐范围：100-200

## 扩展功能

### 播报详细物品名称

如果需要播报具体检测到的物品名称，可以修改调用方式：

```python
# 在 app.py 的 _detect_image 方法中
self.voice_service.announce_detection(self.current_result, announce_all=True)
```

这样会播报：`"检测到苹果核、香蕉皮等，请投入绿色厨余垃圾桶"`

### 自定义播报文本

可以使用 `announce_text()` 方法播报自定义内容：

```python
self.voice_service.announce_text("欢迎使用垃圾分类检测系统")
```

## 性能说明

- **线程播报**：语音播报在独立线程中执行，不影响检测性能
- **内存占用**：语音引擎占用约10-20MB内存
- **CPU占用**：播报时CPU占用<5%
