## 一、TACO / YOLOv8 trash 检测数据集（Roboflow）

### 1. 访问与下载（YOLOv8 格式）

- 打开浏览器访问：  
  `https://universe.roboflow.com/waste-detector/taco-yolo-10-class-original`
- 步骤：
  1. 登录你的 Roboflow 账号。
  2. 左侧点击 `Dataset`，中间 `Versions` 选择最新版本（你截图中的 `v4: 2_TACO-640px-10class-80-10-10` 推荐使用）。
  3. 在上方 **格式按钮** 区域点击 **`YOLOv8`**（或 `YOLOv5 / YOLOv8`）。
  4. 在弹出窗口保持默认的 train/valid/test 划分，点击 **Download**，得到一个 `.zip` 压缩包（文件名类似 `...taco-640px-10class-80-10-10_yolov8.zip`）。

### 2. 下载后的文件结构

解压后典型结构为（YOLOv8 标准）：

```text
taco-yolo10/
  ├─ data.yaml
  ├─ train/
  │   ├─ images/
  │   └─ labels/
  ├─ valid/
  │   ├─ images/
  │   └─ labels/
  └─ test/
      ├─ images/
      └─ labels/
```

- `images/`：JPEG/PNG 图片。
- `labels/*.txt`：YOLO 格式标注：  
  `class_id x_center y_center width height`（0~1 归一化）。
- `data.yaml`：数据集配置，包含 `train`, `val`, `test` 路径和 `names` 类别列表（10 类）。

这是一个**家庭有机厨余 + 非有机污染物的图像+语义分割数据集**，你需要把分割 mask 转换成 YOLO 检测框。

  `Image Dataset of Domestic Organic Waste and Non-Organic Contaminants for Classification and Segmentation`
- 访问方式：

### 2. 下载后的文件结构（典型）


你需要在 README/说明文件中确定各个像素值对应的类别，例如（示意）：

- 0 = 背景
- 1 = organic
- 2 = non-organic

### 4. 从分割 mask 转成 YOLOv8 检测标注

目标：生成一个 YOLOv8 风格的数据集，例如 `datasets\domestic_yolo`：

```text
datasets/
  domestic_yolo/
    ├─ images/
    │   └─ train/
    └─ labels/
        └─ train/
```

映射策略（与你系统对齐）示例：

- mask 中 `organic` → YOLO 类别：**厨余垃圾**（假设是 `class_id = 0`）
- mask 中 `non-organic` → YOLO 类别：**可回收/干垃圾**（假设是 `class_id = 1`）

可以在项目 `scripts/` 目录写一个转换脚本（伪代码示意）：

```python
# scripts/convert_domestic_to_yolo.py
import os
import cv2
import numpy as np

SRC_IMG_DIR = r"datasets/domestic_raw/images"
SRC_MASK_DIR = r"datasets/domestic_raw/masks"

OUT_IMG_DIR = r"datasets/domestic_yolo/images/train"
OUT_LABEL_DIR = r"datasets/domestic_yolo/labels/train"

os.makedirs(OUT_IMG_DIR, exist_ok=True)
os.makedirs(OUT_LABEL_DIR, exist_ok=True)

# 假设 mask 中：1=organic, 2=non-organic
PIXEL_TO_CLASS = {
    1: 0,  # organic -> kitchen_waste
    2: 1,  # non-organic -> recyclable
}

for fname in os.listdir(SRC_IMG_DIR):
    if not fname.lower().endswith((".jpg", ".jpeg", ".png")):
        continue

    img_path = os.path.join(SRC_IMG_DIR, fname)
    mask_path = os.path.join(SRC_MASK_DIR, fname.replace(".jpg", "_mask.png").replace(".png", "_mask.png"))

    if not os.path.exists(mask_path):
        continue

    img = cv2.imread(img_path)
    h, w = img.shape[:2]
    mask = cv2.imread(mask_path, cv2.IMREAD_GRAYSCALE)

    yolo_lines = []

    for pixel_value, cls_id in PIXEL_TO_CLASS.items():
        # 取该类的区域
        binary = (mask == pixel_value).astype(np.uint8)
        # 找轮廓
        contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
        for cnt in contours:
            x, y, bw, bh = cv2.boundingRect(cnt)
            # 过滤太小的框（避免噪声）
            if bw < 5 or bh < 5:
                continue
            x_center = (x + bw / 2) / w
            y_center = (y + bh / 2) / h
            ww = bw / w
            hh = bh / h
            yolo_lines.append(f"{cls_id} {x_center} {y_center} {ww} {hh}")

    # 复制图片到 OUT_IMG_DIR
    out_img_path = os.path.join(OUT_IMG_DIR, fname)
    if not os.path.exists(out_img_path):
        os.makedirs(os.path.dirname(out_img_path), exist_ok=True)
        cv2.imwrite(out_img_path, img)

    # 写 label
    label_name = os.path.splitext(fname)[0] + ".txt"
    out_label_path = os.path.join(OUT_LABEL_DIR, label_name)
    with open(out_label_path, "w", encoding="utf-8") as f:
        f.write("\n".join(yolo_lines))
```

> 上面是示意脚本，你可以按实际 mask 文件名规则和像素值做调整。

在 PowerShell 中运行转换：

```powershell

```

然后再为 `domestic_yolo` 写一个 `data.yaml`（备用）：

```yaml

  0: kitchen_waste
```

```powershell
Expand-Archive -Path "$env:USERPROFILE\Downloads\medical-waste2*yolov8*.zip" -DestinationPath "datasets\hazardous_med2"
```

> 实际文件名请按下载结果替换。

### 3. 文件结构与是否需要转换

结构同 TACO：

```text
datasets/
  hazardous_med1/
    ├─ data.yaml
    ├─ train/images, train/labels
    ├─ valid/images, valid/labels
    └─ test/...
  hazardous_med2/
    └─ 同上
```

- **格式上**：已经是 YOLOv8，无需再做 COCO→YOLO 转换。
- 需要做的是 **类别统一映射**：
  - 比如你全局类定义：
    - 0: kitchen_waste
    - 1: recyclable
    - 2: hazardous
    - 3: other
  - 那么 `hazardous_med1` / `2` 中所有类都可以映射到 `class_id = 2`（有害垃圾）。

示例映射脚本（放 `scripts/remap_hazardous_labels.py`）：

```python
import os

NEW_CLASS_ID = 2  # 有害垃圾的索引
DATASETS = [
    r"datasets/hazardous_med1",
    r"datasets/hazardous_med2",
]

def remap_root(root):
    for split in ["train", "valid", "test"]:
        lbl_dir = os.path.join(root, split, "labels")
        if not os.path.exists(lbl_dir):
            continue
        for fname in os.listdir(lbl_dir):
            if not fname.endswith(".txt"):
                continue
            path = os.path.join(lbl_dir, fname)
            new_lines = []
            with open(path, "r", encoding="utf-8") as f:
                for line in f:
                    parts = line.strip().split()
                    if not parts:
                        continue
                    parts[0] = str(NEW_CLASS_ID)
                    new_lines.append(" ".join(parts))
            with open(path, "w", encoding="utf-8") as f:
                f.write("\n".join(new_lines))

for root in DATASETS:
    remap_root(root)
```

PowerShell 中运行：

```powershell
cd "d:\Data\code\YOLOv8 - new"
python scripts\remap_hazardous_labels.py
```

然后，把各自 `data.yaml` 中的 `names` 改成你的全局 4 类即可（供单独调试用）。
