## 一、项目概述

本项目是一个基于YOLOv8深度学习目标检测算法的智能垃圾分类识别系统，应用于智能家居场景（厨房环境），实现垃圾的自动识别与分类指导。

### 核心功能
- **图片检测**：单张/批量图片垃圾识别
- **视频检测**：视频文件逐帧检测
- **摄像头检测**：实时画面检测
- **分类指导**：四大类（厨余/可回收/有害/其他）投放指导
- **统计功能**：检测记录、分类统计、CSV导出

### 技术栈
- **深度学习框架**：Ultralytics YOLOv8
- **GUI框架**：PyQt5
- **图像处理**：OpenCV
- **编程语言**：Python 3.8+

## 三、核心模块详细说明

### 3.1 主程序文件

#### `main.py` - 主程序入口

**功能**：应用程序主入口，整合所有模块实现完整功能。

**核心类**：
- `VideoThread`：视频/摄像头处理线程
  - 异步读取视频帧
  - 调用检测服务
  - 发送检测结果信号
- `MainWindow`：主窗口类
  - 初始化各模块组件
  - 连接信号槽
  - 处理用户交互

**关键方法**：
| 方法 | 功能 |
|------|------|
| `on_open_image()` | 打开单张图片 |
| `on_open_folder()` | 打开图片文件夹 |
| `on_open_video()` | 打开视频文件 |
| `on_toggle_camera()` | 切换摄像头 |
| `on_save()` | 保存检测结果 |
| `_detect_image()` | 执行图片检测 |
| `_start_video()` | 启动视频处理 |
| `_update_statistics_display()` | 更新统计显示 |

---

#### `detection_service.py` - 检测服务模块

**功能**：封装YOLOv8模型加载和推理逻辑。

**核心类**：
- `DetectionResult`：检测结果数据类
  - `locations`：检测框坐标
  - `classes`：类别ID列表
  - `confidences`：置信度列表
  - `elapsed_time`：推理耗时
- `DetectionService`：检测服务类
  - 加载YOLO模型
  - 执行目标检测
  - 预热模型

**关键方法**：
| 方法 | 功能 |
|------|------|
| `detect(source)` | 执行检测，返回DetectionResult |
| `get_plotted_image()` | 获取绘制检测框的图像 |
| `get_classification_guide()` | 获取分类指导信息 |

---

#### `ui_manager.py` - UI管理模块

**功能**：管理UI界面显示和更新。

**核心类**：`UIManager`

**关键方法**：
| 方法 | 功能 |
|------|------|
| `display_image()` | 在QLabel上显示图像 |
| `update_result_table()` | 更新检测结果表格 |
| `update_detection_info()` | 更新检测信息标签 |
| `show_classification_guide()` | 显示分类指导 |

---

#### `file_handler.py` - 文件处理模块

**功能**：文件类型判断、路径生成、文件操作。

**核心类**：`FileHandler`

**关键方法**：
| 方法 | 功能 |
|------|------|
| `is_image_file()` | 判断是否为图片文件 |
| `is_video_file()` | 判断是否为视频文件 |
| `get_images_from_directory()` | 从目录获取所有图片 |
| `generate_save_path()` | 生成保存路径 |

---

#### `statistics_manager.py` - 统计管理模块

**功能**：检测记录存储、统计分析、数据导出。

**核心类**：`StatisticsManager`

**数据存储**：`save_data/statistics.json`

**关键方法**：
| 方法 | 功能 |
|------|------|
| `add_record()` | 添加检测记录 |
| `get_today_statistics()` | 获取今日统计 |
| `get_category_statistics()` | 获取分类统计 |
| `export_to_csv()` | 导出CSV文件 |
| `clear_records()` | 清空所有记录 |

### 3.2 配置文件

#### `Config.py` - 运行时配置

**功能**：定义类别映射、模型路径、分类指导等核心配置。

**关键配置项**：
```python

model_path = 'models/best.pt'    # 模型文件路径
NUM_CLASSES = 5 或 40            # 类别数量
names = {...}                    # 类别英文名映射
CH_names = [...]                 # 类别中文名列表
classification_guide = {...}     # 四大类分类指导
```

## 五、使用指南

### 5.1 快速开始（5类模式）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 训练模型（可选，如已有best.pt）
python train.py

# 3. 复制模型到models目录
cp runs/detect/kitchen_garbage_5cls/weights/best.pt models/

# 4. 运行应用
python main.py
```

### 5.2 40类精细化模式

```bash
# 1. 切换到40类配置
python switch_config.py 40

# 2. 训练40类模型
python train_40cls.py

# 3. 复制模型
cp runs/detect/garbage_40cls/weights/best.pt models/best_40cls.pt

# 4. 运行应用
python main.py
```

### 5.3 切换模式

```bash
# 切换到5类
python switch_config.py 5

# 切换到40类
python switch_config.py 40
```
