## 一、项目概述

本项目是一个基于YOLOv8深度学习目标检测算法的智能垃圾分类识别系统，应用于智能家居场景（厨房环境），实现垃圾的自动识别、分类指导及语音播报。

### 核心功能
- **图片检测**：单张/批量图片垃圾识别
- **视频检测**：视频文件逐帧检测
- **摄像头检测**：实时画面检测
- **语音播报**：四大类（厨余/可回收/有害/其他）投放语音指导
- **统计功能**：检测记录、分类统计、CSV导出

## 三、核心模块详细说明

### 3.1 源代码 (src/)

#### `src/config/settings.py`
**功能**：全局配置中心。包含路径常量、模型注册（CONFIG_REGISTRY）、分类类别映射及颜色提示。

#### `src/core/detection_service.py`
**功能**：封装 YOLOv8 推理引擎。提供 `detect()` 接口，返回包含坐标、类别和置信度的 `DetectionResult` 对象。

#### `src/core/voice_service.py`
**功能**：多线程语音播报服务。通过 `pyttsx3` 实现，具备智能防重复播报机制。

#### `src/core/statistics_manager.py`
**功能**：数据统计与持久化。将检测结果保存至 JSON，并支持导出为 CSV 报表。

### 3.2 其它重要目录

- **data/models/trained/**：存放训练好的 `.pt` 模型文件。
- **output/**：所有运行产生的检测图片、视频和统计报表均保存在此。
- **training/**：包含 `train.py` 等训练脚本及训练过程记录。

## 五、使用指南

### 5.1 快速开始（5类模式）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 训练模型（可选，如已有best.pt）
python train.py

# 3. 复制模型到models目录
cp runs/detect/kitchen_garbage_5cls/weights/best.pt models/

# 4. 运行应用
python main.py
```

### 5.2 40类精细化模式

```bash
# 1. 切换到40类配置
python switch_config.py 40

# 2. 训练40类模型
python train_40cls.py

# 3. 复制模型
cp runs/detect/garbage_40cls/weights/best.pt models/best_40cls.pt

# 4. 运行应用
python main.py
```

### 5.3 切换模式

```bash
# 切换到5类
python switch_config.py 5

# 切换到40类
python switch_config.py 40
```
