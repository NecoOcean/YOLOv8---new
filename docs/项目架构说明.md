## 二、模块说明

### 2.1 src/config/settings.py
统一配置管理，当前默认支持 4 类混合垃圾分类模型。

主要功能：
- **路径配置**：通过 `Path` 对象管理项目根目录、数据、模型及输出路径。
- **模型注册**：在 `CONFIG_REGISTRY` 中定义模型路径、类别映射（中文/英文）及视觉颜色。
- **分类指导**：定义各类别对应的垃圾桶类型及投放提示语。
- **模式获取**：提供 `get_current_config()` 获取当前激活的配置字典。

### 2.2 src/core/detection_service.py
核心检测服务模块。

- `DetectionResult`: 检测结果数据类
- `DetectionService`: YOLO模型封装，提供检测接口

### 2.3 src/core/statistics_manager.py
统计管理模块。

- 检测记录存储和查询
- 今日统计、分类统计、类别统计
- CSV导出功能

### 2.4 src/ui/ui_manager.py
UI管理模块，负责界面更新。

- 图像显示
- 结果表格更新
- 分类指导显示
- 统计面板更新

### 2.5 src/utils/file_handler.py
文件处理工具类。

- 文件类型判断
- 路径生成
- 目录操作

## 三、使用方法

### 3.1 运行应用
```
# 直接运行主入口
python app.py
```

### 3.2 训练模型
```
# 切换到训练目录执行脚本
cd training
python train.py
```

### 3.3 查看当前配置
```
# 使用工具脚本查看或维护配置
python scripts/switch_config.py show
```

## 四、开发指南

### 4.1 添加新模块
1. 在 `src/` 下创建相应目录
2. 添加 `__init__.py`
3. 在父模块的 `__init__.py` 中导出

### 4.2 修改配置
编辑 `src/config/settings.py`，所有配置集中管理。

### 4.3 运行测试
```
cd tests
python -m pytest
```

## 五、迁移说明

新代码导入方式：
```
from src.config import settings
from src.core import DetectionService
```

## 六、注意事项

1. **路径问题**：项目全面采用基于项目根目录的相对路径
2. **模型路径**：所有训练好的模型文件必须放置在 `data/models/trained/` 目录下
3. **依赖安装**：新增语音功能，确保已安装 `pyttsx3`
