## 二、模块说明

### 2.1 src/config/settings.py
统一配置管理，支持5类和40类动态切换。

主要功能：
- 路径配置（项目根目录、数据目录、输出目录）
- 模型配置（预训练模型、训练后模型路径）
- 类别配置（5类和40类的名称、分类指导）
- 模式切换（`set_mode('cls5')` 或 `set_mode('cls40')`）

### 2.2 src/core/detection_service.py
核心检测服务模块。

- `DetectionResult`: 检测结果数据类
- `DetectionService`: YOLO模型封装，提供检测接口

### 2.3 src/core/statistics_manager.py
统计管理模块。

- 检测记录存储和查询
- 今日统计、分类统计、类别统计
- CSV导出功能

### 2.4 src/ui/ui_manager.py
UI管理模块，负责界面更新。

- 图像显示
- 结果表格更新
- 分类指导显示
- 统计面板更新

### 2.5 src/utils/file_handler.py
文件处理工具类。

- 文件类型判断
- 路径生成
- 目录操作

## 三、使用方法

### 3.1 运行应用
```bash
# 新版入口（推荐）
python app.py

# 旧版入口（保持兼容）
python main.py
```

### 3.2 训练模型
```bash
# 统一训练入口
cd training
python train.py --mode cls5 --epochs 100   # 5类训练
python train.py --mode cls40 --epochs 100  # 40类训练
```

### 3.3 切换配置
```bash
cd scripts
python switch_config.py 5    # 切换到5类
python switch_config.py 40   # 切换到40类
```

## 四、开发指南

### 4.1 添加新模块
1. 在 `src/` 下创建相应目录
2. 添加 `__init__.py`
3. 在父模块的 `__init__.py` 中导出

### 4.2 修改配置
编辑 `src/config/settings.py`，所有配置集中管理。

### 4.3 运行测试
```bash
cd tests
python -m pytest
```

## 五、迁移说明

旧代码导入方式：
```python
import Config
from detection_service import DetectionService
```

新代码导入方式：
```python
from src.config import settings
from src.core import DetectionService
```

## 六、注意事项

1. **向后兼容**：旧版 `main.py` 保留，可继续使用
2. **路径问题**：新架构使用相对于项目根目录的路径
3. **模型路径**：需要将模型放到 `data/models/trained/` 目录
